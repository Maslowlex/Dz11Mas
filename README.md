## Алгоритм решения
1. **НАЧАЛО**
2. Объявление массива `products` из 3 элементов типа `Product` и счетчика `i`.
3. **Цикл ввода (для i от 0 до 2):**
   * Вывод заголовка "Ввод товара №...".
   * Запрос и ввод наименования товара.
   * Запрос и ввод даты производства.
   * Запрос и ввод срока годности (дата "годен до").
   * Запрос и ввод цены.
   * Запрос и ввод номера серии.
4. Вывод заголовка "Результат (Товар: годен до)".
5. **Цикл вывода (для i от 0 до 2):**
   * Вывод наименования товара `products[i].name`.
   * Вывод конечной даты применения `products[i].expiryDate`.
6. **КОНЕЦ**
